# البدائل والمعايير والتجارب

المصحح يسأل سؤالاً واحداً هنا: هل البدائل حقيقية، أم مجرد قش لتبرير خيار محسوم من البداية؟ والمحلل الجيد يعرض البدائل بحياد، ثم يرجّح بمعايير معلنة.

## 1. بناء البدائل

- **ثلاثة إلى خمسة بدائل**، كل منها قابل للتنفيذ فعلاً ويدافع عنه أحد.
- **الوضع القائم** بديل إلزامي، وتقيّمه بالمعايير نفسها. «عدم الفعل» له كلفة، وإظهارها يقوّي الحجة.
- **مقترح المعارضين**: إن كان هناك من يقترح حلاً مختلفاً (تشديد العقوبات مثلاً)، فأدرجه وقيّمه بإنصاف.
- نوّع **أنواع الأدوات**: تنظيمية (قوانين، لوائح)، واقتصادية (حوافز، رسوم، ضرائب)، ومعلوماتية (نشر، توعية)، وتقديم مباشر للخدمة، وشراكات، ومزيج منها.
- لا تخلط بين البديل والمعيار (تحذير باردَك): «كلفة منخفضة» معيار، لا بديل.

## 2. المعايير

المعايير الست الشائعة لاختيار الأداة:

| المعيار | السؤال |
|---|---|
| الفعالية | هل يحقق الأهداف؟ هل يعالج الأسباب؟ |
| الكفاءة | ما الكلفة مقابل النتيجة؟ |
| العدالة | كيف تتوزع الأعباء والمنافع؟ من يُظلم؟ |
| الجدوى السياسية | هل يقبله صانع القرار والفاعلون النافذون؟ |
| القدرة الإدارية | هل تملك الجهة الكوادر والأنظمة لتنفيذه؟ |
| المشروعية | هل له سند قانوني؟ هل يقبله المجتمع؟ |

- إن طلب القالب معايير محددة (الجدوى السياسية والاقتصادية والإدارية مثلاً)، فاستخدمها بالاسم.
- يمكن إضافة **معيار مركّب** مستخلص من التجارب (انظر 3).
- اذكر في سطر واحد أن التقديرات نوعية إن لم تكن كمية، و«مرتفعة» تعني الأفضل (أو العكس للكلفة).

## 3. التجارب الدولية أداة تحليل

الخطأ الشائع: سرد تجارب ناجحة للزينة. الطريقة الأقوى:

1. اجمع 5 إلى 8 تجارب، **ناجحة وفاشلة**. التجربة الفاشلة تعلّم أكثر لأنها تكشف ما يجب تجنبه.
2. لكل تجربة: ماذا فعلت، ولماذا نجحت أو فشلت، والدرس للمذكرة، والأداة المقابلة في التوصية.
3. استخرج **ما يجمع الناجحة** و**ما يجمع الفاشلة**.
4. حوّل ما يجمع الناجحة إلى **معيار نجاح** من عناصر واضحة (مثال: معالجة السبب، قياس معلن، مساءلة صاحب السلطة أولاً، أداة اقتصادية صغيرة عند لحظة السلوك)، واستخدمه عموداً في جدول البدائل («عناصر النجاح: 4 من 4»).
5. وزّع التجارب: الأقوى دلالة في المتن بجملة لكل منها، والجدول الكامل في ملحق.
6. **تحقق** من كل رقم وتاريخ في التجارب، واذكر المصدر.

## 4. مصفوفة المقارنة

| البديل | الفعالية | الكفاءة | العدالة | الجدوى السياسية | القدرة الإدارية | عناصر النجاح |
|---|---|---|---|---|---|---|
| الوضع القائم | | | | | | |
| ... | | | | | | |

- اجعل البديل الموصى به بخط عريض.
- **لا تضع الجدول بدل الكتابة** (تنبيه مدرسة كينيدي). بعد الجدول، فقرة «نتيجة المقارنة» تشرح لماذا يتفوق الخيار، وما المقايضة التي يقبلها.
- **واجه المقايضات**: لا يوجد بديل يتفوق في كل شيء. قل ما يخسره الخيار الموصى به وكيف يُعوَّض.

## 5. اختبار التسلسل

التوصية يجب أن تنبع من نتيجة المقارنة. افحص: هل الخيار الموصى به هو الأعلى في المعايير التي يهتم بها المخاطَب؟ إن لم يكن، فإما أن الترجيح يحتاج تبريراً صريحاً، أو أن التقييم متحيز.

## مخرج المحطة
- قائمة البدائل مع وصف سطرين لكل منها.
- جدول التجارب (ناجحة وفاشلة) ومعيار النجاح.
- مصفوفة المقارنة وفقرة «نتيجة المقارنة».
